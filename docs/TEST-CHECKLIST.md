# Checklist di test (da spuntare giocando su PC)

Avvio: `avvia-test-pc.bat` → http://localhost:5173 · pannello di test: `Ctrl+Maiusc+D`.
Per ogni problema: usa *Segnala un problema* nel pannello e mandami il file `.md` (o descrivilo a parole).

## Generale
- [ ] La home mostra «Inizia l'indagine» e, dopo aver giocato, «Continua»
- [ ] Chiudendo e riaprendo il browser la partita riprende dall'ultima scena
- [ ] Tasti: Spazio/Invio/→ avanti, 1-3 scelte, Q quaderno
- [ ] Impostazioni: testo grande, contrasto alto, riduci animazioni, carattere leggibile cambiano subito l'aspetto
- [ ] Esporta → Cancella tutto → Importa: la partita torna identica
- [ ] 3 slot: salva, carica, elimina
- [ ] «Ricomincia» un capitolo chiede conferma e azzera le scelte di quel capitolo

## Capitolo 1 — È vero?
- [ ] Le tre prime scelte portano a scene diverse e poi si ricongiungono (prova tutte e tre)
- [ ] Solo se hai inoltrato (scelta 1) compare la scena «Come rimedi?»
- [ ] Esame del messaggio: i 6 segnali si trovano; «Valdorna», l'istruzione sull'acqua e «Inoltrato più volte» sono spiegati come *non prove*
- [ ] Verdetto sbagliato → spiegazione calma, si può riprovare; dopo 3 errori mostra la soluzione
- [ ] Aiuto 1, 2, 3: testi coerenti, nessuna penalità sulle stelle
- [ ] Laboratorio: aprire due fonti prima di decidere; «Metti tra le prove» funziona; feedback sulle fonti deboli
- [ ] Timeline: frecce su/giù, «Controlla» segna giusto/da ripensare, «Mostrami l'ordine corretto»
- [ ] Zia Lina: le tre risposte hanno conseguenze diverse
- [ ] Il Quaderno mostra prove (con «indizio debole»), bacheca, timeline, glossario (termini sbloccati), caso «squalo»
- [ ] La scena finale mostra l'SMS di rimborso e il riepilogo «Che cosa hai imparato»
- [ ] Dialoghi: sono chiari? ci sono frasi troppo difficili? (annota)

## Modalità
- [ ] Casi quotidiani (3): il caso del dentista si risolve con «sembra regolare»
- [ ] Allenamento guidato mostra il metodo a 4 passi
- [ ] Redazione (fatti/opinioni/ipotesi) e Recupero account (ordinamento)
- [ ] Laboratorio libero: incolla l'SMS del pacco → segnala fretta, pagamento, dominio; incolla una frase innocua → nessun segnale
- [ ] Ripasso si sblocca dopo il cap. 1
- [ ] «Se succede davvero»: 5 guide leggibili
- [ ] Casi reali: i link si aprono e coincidono con la scheda

## Build finale e iPad (quando pubblicata)
- [ ] `gioca-pc.bat`: nessun pannello di test, nemmeno con `?debug=1`
- [ ] Offline: DevTools → Rete → Offline → ricarica: il gioco si apre
- [ ] iPad: Aggiungi alla Home, apri, modalità aereo, il gioco funziona
- [ ] iPad: rotazione verticale/orizzontale, tocchi comodi, nessuno zoom necessario
- [ ] iPad: Esporta partita → salva in File → Importa su PC (o viceversa)

## Capitoli 2–8
- [ ] Ogni capitolo si gioca dall'inizio alla fine; il capitolo successivo si sblocca.
- [ ] Le prove compaiono nel quaderno solo dopo la scoperta, senza duplicati; le prove deboli sono segnate.
- [ ] Capitolo 8: i quattro finali (A–D) sono raggiungibili e ogni scelta sbagliata si può rigiocare.
- [ ] Salvataggio del capitolo 1 caricato: il gioco prosegue dal capitolo 2.
